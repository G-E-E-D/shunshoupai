# 顺手排

把脑子里的安排，变成看得见的日程。基于 Next.js、TypeScript，支持账号隔离、可编辑草稿、确认保存和跨设备同步。

> 开发进行中。实现与验收记录会随阶段提交更新；原始方案见 [AI日程应用可行性与技术方案.md](AI日程应用可行性与技术方案.md)。

- [ ] 账号、持久化、事务与日程 API
- [ ] 自然语言解析、草稿预览与响应式界面
- [ ] 集成验证、展示材料与运行说明

需要 Node.js 24 或更新的 LTS 版本。首次运行：`npm install`，然后 `npm run dev`。

本地模式使用真正的独立账号和 SQLite 持久化，共用同一个服务地址的设备可以同步。云端模式使用 Supabase。模型接口为可配置的 OpenAI 兼容接口；没有密钥时只启用明确标记的有限规则解析。
