# 打开就记，需要同步时再扫码

顺手排 v2.1.0-beta.1 不需要日程账号、邮箱或密码。电脑打开应用即可使用本机日程；手机安装后也能独立新增、修改、完成、删除和搜索，电脑不在线时照常记录。

## 先把安排记下来

Windows 安装包包含原生 Qt 界面、Go 和本机数据库服务，不用另外安装运行环境。手机首页是原生日程，不必先扫描或等待电脑。

电脑可以手工创建日程，也可以输入：

> 明天下午三点到四点面试，今天晚上七点到八点改简历，八点到九点准备面试。

点击“整理日程”，检查草稿里的具体日期、标题和起止时间，再确认保存。可以修改或移除草稿；暂时关闭后能继续编辑。网页里的对应按钮是“帮我整理一下”。时间统一采用上海时区。

没有配置模型时，界面明确标记“规则解析”。时间含糊时补充说明；整理结果只是草稿，不会自动成为正式日程。手动添加适合已经想清楚的单项安排。

## 任意两台设备接着用

1. 两端都更新到 v2.1.0-beta.1，并连接同一个可信 Wi-Fi。
2. 其中一台电脑或手机打开“配对设备”，展示自己的二维码或配对链接。
3. 另一台设备扫码或粘贴配对链接，阅读共享范围并确认。
4. 配对后自动尝试合并。对方离线时继续在本机记录；安卓应用需保持前台才能接收同步。

Windows 安装版服务端口为 **43127**，同步时电脑应用需运行，并允许可信局域网访问该端口。手机的接收地址和端口以配对页为准。配对码 **90 秒有效、只能使用一次**，不要转发。只填写一个地址不会获得访问权限；暂不配对也能继续使用本机日程。

支持电脑与电脑、电脑与安卓、安卓与安卓两两连接，可配对多台。每台设备维护自己的主日程；配对会共享全部日程及未来修改，也可能经对方传播到其其他已配对设备。模型密钥不传播。不同日程即使时间重叠也保留；同一日程的并发修改或删除保留全部版本，没有预选结果，明确选择后再同步。

任一设备地址变化时，重新生成并扫描一次性码。核对原设备身份后继续同步，不向新地址发送旧的长期凭据。取消配对只停止后续授权，不能撤回两端或其他设备已经保存的副本。

## 需要智能整理时

电脑点击“模型设置”；手机先连接电脑，再打开“电脑工具”，在网页的“设备与同步”中进入模型设置。填写服务商提供的 Base URL、模型名称和 API Key，先测试，再保存。测试会发起一次模型请求，可能消耗服务商额度。

提示词由程序固定。模型 Key 加密保存在当前电脑，页面只显示掩码；配对设备可以使用这份配置。手机的网页智能整理和模型设置需要电脑在线，离线 AI 尚未提供。详见[模型设置](model-settings.md)。

## 升级和边界

旧本机只有一份资料时沿用；有多份资料时，首次选择继续使用的一份，其余仍保留。原事件 ID、版本、草稿和未确认的保存编号继续使用。手机保留历史资料，明确导入后才进入主日程，不会把不同来源自动混合。

配对身份签名用于识别设备，**不等于 TLS 或端到端加密**；当前仅面向可信局域网。后台自动同步、可靠锁屏提醒和公网托管尚未提供。旧 Supabase 部署不能直接运行 v2，且没有自动导入界面，见[旧云端迁移边界](cloud-setup.md)。
