# 打开就记，需要同步时再扫码

顺手排 2.2.0 不需要日程账号、邮箱或密码。电脑和手机都有自己的本机日程、整理草稿和模型设置；没有配对或另一端关闭时也能继续使用。安装包见[发布列表](https://github.com/G-E-E-D/shunshoupai/releases)。

## 先把安排记下来

安装后直接打开，用“新日程”手工记录，也可以描述安排：

> 明天下午三点到四点面试，今天晚上七点到八点改简历，八点到九点准备面试。

电脑点击“整理日程”或按 Ctrl+Enter；手机打开“智能整理”，输入后点击“整理成草稿”。检查具体日期、标题和起止时间，可以修改、移除或取消勾选条目，再确认保存。整理结果不是正式日程，恢复旧稿也不会自动保存。

没有配置模型时可用本机有限规则。时间含糊时补充说明，有默认假设时先核对提示。日期统一按上海时区，“今天”“明天”参考实际日期，不随日历浏览位置改变。

暂时不处理时，电脑选择“暂不保存”，手机选择“稍后继续”，原文和未确认草稿会保留。手机的“保存已选”固定在草稿页底部；时间重叠或其他校验失败时，修改后再保存，不会部分写入一批日程。

## 查看、查找和提醒

用“日程”“七天”“已完成”查看安排。手机点击日期打开月历，左右按钮翻页，“今天”回到当前日期；“七天”从选中日期起算连续七天，“已完成”列出全部已完成项目，可恢复为未完成。

手机在“日程/七天”页搜索全部未完成安排，在“已完成”页搜索全部已完成安排，不限于正在查看的日期。

手机使用系统闹钟在开始前五分钟提醒，后台和锁屏时也可通知；新安装默认开启，旧版明确关闭的选择保留。首页提示缺少的权限，点一次可依次设置通知与锁屏运行。完成、删除或待解决冲突不提醒；点击通知打开对应日期。详见[后台与提醒设置](background-operation.md)。

## 从其他页面取字

### Windows

打开主程序后，点击“截图”或按 **Ctrl+Alt+S**，拖动框选文字，松开后由本机 Java/Tess4J OCR 识别；按 Esc 可取消。核对并编辑识别文字，确认后进入原来的日程草稿，再检查并保存。

已有输入时默认“追加并整理”，也可以明确选择替换；已有未确认草稿或待核对保存结果时，先在主程序处理。暂时不整理可选“稍后继续”，以后从“继续识别文字”恢复。超过 2000 字会提示缩短，不会自动截断。

可拖动悬浮入口**默认关闭**，在“截图”旁的设置中开启或关闭。快捷键被占用时仍可点截图按钮；退出主程序后快捷键和浮窗停止。安装包已带 Java 运行时和中英文模型，无需另装；锁屏时不能保证屏幕捕获。

### Android

点击首页“取字”并主动开启，按系统提示授予悬浮显示和屏幕捕获权限。系统允许选择单个应用或整个屏幕；功能默认关闭，普通日程使用不需要这些权限。

切到要取字的页面，点击悬浮按钮，在预览中拖出选区，点击“识别选区”。核对文字后点击“整理成草稿”；若已有原稿，会先提供追加或稍后处理，不静默替换。生成的草稿仍需点击“保存已选”。

同一次授权会话可连续截图。前台通知、长按悬浮按钮或首页“取字中”都提供停止方式；在本应用前台时悬浮按钮暂时隐藏。停止、锁屏或系统撤销后，下次重新授权。通知权限可选，拒绝通知后仍可从悬浮按钮或首页停止。受保护画面可能显示黑屏，应用不会绕过系统限制。

两端图片都只在本机处理，不发送给模型，也不随配对传播。**确认文字并开始整理后，若配置了模型，文字会发送到当前设备自己的模型服务。** Android OCR 模型随包可离线首用；其组件可能发送性能和使用统计，详见[Android 说明](android.md)。

## 各设备分别配置模型

电脑点击“模型设置”，手机点击“模型”。填写自己信任的 Base URL、模型名称和 API Key，先测试，再保存。测试会发起请求，可能消耗服务商额度，但不会自动保存配置。

模型 Key 加密保存在当前设备，不通过配对分享；手机无需打开电脑网页。电脑关闭但手机可以连接模型服务时，手机仍可直连。完全断网时，可继续手动安排、使用有限规则、恢复草稿、查看日程和本机 OCR；不可达的模型服务无法调用，本地规则不是离线大模型。详见[模型设置](model-settings.md)。

## 任意两台设备接着用

1. 两端更新到相同版本，连接同一个可信局域网；首次配对时打开手机应用，之后可使用后台同步。
2. 一端打开设备连接入口，展示自己的二维码或配对链接。
3. 另一端扫码或粘贴链接，阅读共享范围并确认。Windows 也可识别二维码图片或粘贴图片，不提供相机实时扫码。
4. 配对后自动尝试合并。对方离线时继续本机记录；重新互通并打开应用后再同步。

支持电脑↔电脑、电脑↔安卓、安卓↔安卓及多设备连接。Windows 安装版通常监听 **43127**，手机地址和端口以配对页为准。配对码 **90 秒有效且只能使用一次**，普通地址不能代替授权。

配对共享本机全部正式日程及未来修改，也可能经对方继续传播到其他已配设备；模型密钥、草稿和截图不传播。不同日程即使时间重叠也会保留；同一日程的并发修改或删除会保留全部不同版本，明确选择后再同步。

地址变化时，在原设备重新生成并扫描一次性码，核对稳定身份后继续同步，不向新地址发送旧长期凭据。取消配对只停止后续授权，不删除本机日程，也不能撤回已经传播的副本。配对身份签名不等于 TLS 或端到端加密，请只在可信局域网使用。

## 升级与使用边界

Windows 安装包保留 Qt 主界面、Next.js/Node 本机服务，并带 Java 截图组件；升级时保留本机用户数据。Android 正式升级应直接覆盖安装同签名 APK，不要先卸载。

旧本机只有一份资料时沿用，多份资料先在本机选择，其余仍保留。原事件 ID、版本、草稿和未确认保存编号继续使用；其他历史资料明确导入后才进入主日程，不自动混合。

手机后台接收和系统闹钟提醒由独立组件处理，取字服务仍只处理用户授权的截图。强行停止应用后需重新打开；厂商电池策略和通知关闭可能影响运行，不承诺绕过系统限制。当前不提供离线大模型。旧 Supabase 部署不能直接作为当前本机 SQLite 使用，且没有自动导入界面，见[旧云端迁移边界](cloud-setup.md)。
