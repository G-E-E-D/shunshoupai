# 截图取字与日程整理（v2.1.0）

电脑与安卓手机均在本机识别框选区域。流程是：主动截图 → 核对文字 → 整理成草稿 → 确认保存。没有配对设备也可以使用。图片不进入设备同步或模型请求；配置了模型时，确认整理的文字会发送到该设备自行配置的模型服务。

## Windows

1. 打开顺手排，点击“截图”，或在其他窗口按 **Ctrl+Alt+S**。
2. 拖动选择文字区域，松开开始识别；按 **Esc** 取消。
3. 在识别窗口校正文字。已有输入时可追加或明确替换，原有草稿和待核对保存结果会先要求处理。
4. 点击整理，进入现有的日程草稿表格；检查标题、日期和时间，再确认保存。

截图设置可开启可拖动悬浮入口，默认关闭。快捷键冲突时可使用截图按钮或浮窗。未确认文字可“稍后继续”，从主窗口继续识别文字入口恢复；退出主程序会停止浮窗与快捷键。

新增功能使用 Java；原有 Qt 桌面主体与 Node 本机服务保留。安装包包含 Java 运行时、Tesseract 引擎以及简体中文和英文模型，首次识别无需另行下载。识别图片只在内存中处理；暂存文字按本机日程分区，使用当前 Windows 用户的 DPAPI 加密。超时或取消会终止识别任务，旧结果不会覆盖新操作。单次导入最多 2000 字，超限会要求缩短，不静默截断。

## Android

1. 在首页点击“取字”，按说明允许悬浮显示、通知和系统屏幕捕获。
2. 切换到需要识别的应用，点击浮窗，拖动选择区域。
3. 核对识别文字后点“整理成草稿”，使用手机自身的规则或模型设置生成日程；检查后保存。

没有电脑、没有配对或暂时断网时，截图、OCR、规则整理和日程保存仍可独立使用。已有输入或草稿时先核对导入方式，不会自动覆盖。回到主界面时浮窗隐藏，避免遮挡操作；离开后恢复。可长按浮窗、在通知中停止或通过首页停止取字。

每次启动新的屏幕捕获会话都需要 Android 系统授权。同一会话可反复框选；停止、锁屏、权限撤销或系统终止后，需要重新授权。旋转屏幕会取消当前框选，避免取错位置。受系统保护的屏幕内容无法识别，不绕过保护。厂商的后台与悬浮窗限制可能影响使用。

Android 应用代码使用 Java，随 APK 携带 ML Kit 中文 OCR 模型及其原生库。图片、识别文本和输出在设备上处理，SDK 仍可能发送性能、使用情况等指标，详见 [Google ML Kit 条款](https://developers.google.com/ml-kit/terms) 与 [Android 第三方说明](../android/THIRD_PARTY_NOTICES.md)。本机识别不代表整个 SDK 完全没有网络通信。

## 保存与隐私

识别文字进入本机草稿，只有明确确认保存才成为正式日程。未确认文字不会通过设备配对传播；保存后的日程按照已同意的配对范围同步。两端各自保存模型配置与密钥，配对不开放对端模型能力。

截图识别会有误差，尤其是小字、复杂背景和模糊图片。日期缺失、时间推断及规则不支持的表达会在草稿流程中提示；保存前应核对。Windows 使用指南与构建细节见 [Java 模块说明](../desktop-java/README.md)，Android 能力范围见 [手机功能矩阵](mobile-parity.md)。
