# 无账号设备配对与本地同步

v2.1.0 的日常流程只有三步：打开使用、需要同步时扫码、之后自动重连。无需邮箱、密码、注册或云端日程账号。

## 设备与数据

电脑安装包包含 Qt 原生界面和本机 Node/SQLite 服务，启动自动生成本机授权。授权密钥只在该次启动的本机进程之间传递，不根据 Host、Origin 或客户端名称放行。手机使用原生 Java 界面和 SQLite，未配对也能新增、修改、完成、删除、搜索和整理日程。

两端各自配置模型、生成和确认草稿，不依赖另一台设备代为处理。**配对只同步已保存的日程及其修改、删除和冲突版本。** 未保存草稿、截图文字暂存、模型设置和密钥不随配对传播；配对设备不能读取或调用另一台设备的模型功能。

支持电脑↔电脑、电脑↔安卓、安卓↔安卓两两配对，也可连接多台设备。每台设备有自己的主日程和稳定身份，不需要固定中心电脑、共同账号或统一空间。历史资料保留，明确导入后才进入主日程。

## 配对和解除

两台设备连接同一可信局域网。一端展示配对码或链接；手机可相机扫码或粘贴链接，电脑可识别二维码图片、粘贴图片或链接。配对码随机生成，90 秒有效且只能兑换一次；生成新码会作废该入口的旧码。配对成功后建立双向、可撤销的设备授权，不依赖账号会话或周期性密码登录。

配对前需明确同意：**共享本机全部日程及未来修改，内容可能经对方继续流转到其其他已配对设备；模型配置和密钥不随日程传播。** 这是多设备之间的数据传递，不代表其他设备获得本机的直接访问凭据；每条直接连接都需独立授权。

设备列表可查看状态、主动同步和解除配对。解除后停止后续授权，已经保存在任一设备上的副本不会被撤回；离线解除时，也应在另一端撤销该连接。直接连接撤销后，其他仍保留的配对路径可能继续传递同一份日程。

手机回到前台时自动尝试同步，接收服务也仅在前台运行。手机进入后台后，其他设备无法向它同步；回到应用并恢复网络后继续合并。电脑接收同步需要应用及本机服务运行。无网络时照常使用各自本机日程。

## 日程版本与冲突

同步交换事件 ID、不可变修订、完整祖先集合和删除标记。合并只淘汰被另一修订明确继承的旧版本；不用设备时间、设备 ID 或“最后到达”自动决定胜者。多设备环路、丢响应及旧数据重放不会重复创建或复活已被继承的删除。

不同日程即使时间重叠也会保留。同一条日程的并发修改、删除与编辑会保留全部不同内容；界面展示标题、时间、状态和来源，不预选结果。明确选择后生成继承全部已看到版本的新修订；如果确认期间又收到修改，版本检查会要求重新核对。同内容的多个修订可合并展示，但因果信息仍保留。

协议每个事件最多保留 32 个并发修订，每修订最多 2048 个祖先；超限拒绝并报告错误，不静默截断历史。事件分页同步不以某页缺少一项推断删除。

## 地址变化与身份

设备身份与 IP 地址分离。任一设备地址变化后，在原设备重新生成配对码并扫描或粘贴，接收方核对稳定设备 ID 和已记录的公钥，再继续同步本机主日程。

重新扫描新地址时不会向它发送以前保存的长期凭据，只使用用户刚扫描的一次性码重新授权。身份签名使用标准 P-256 / SHA256withECDSA，绑定随机挑战、客户端 ID、设备 ID 和空间 ID，用于核对设备身份；同步本身不要求两端空间相同。它不提供 HTTP 通道加密或对主动中间人的保护，不能替代 TLS；当前连接边界是用户信任的局域网。浏览器获得 HttpOnly Cookie，原生客户端凭据不会通过 JS 桥暴露给页面。

入站授权存储令牌哈希，回连需要的出站凭据加密保存。Node 使用数据库旁的 `model-encryption.key`，电脑备份需同时保留数据库和这份密钥。安卓使用本机 Keystore；复制数据库或设置文件不能迁移 Keystore 密钥，换机或重装后应重新配对、重新填写本机模型配置。

## 升级旧数据

旧版有效本机会话对应的日程继续使用原空间 ID；没有有效会话但只有一份旧资料时自动沿用。存在多份旧资料时，本机仅首次提示选择继续使用的一份，其他资料保留。候选包括尚无正式日程但可能有客户端草稿的旧资料，避免草稿变得不可见。

事件 ID、版本号、未确认操作编号、草稿和模型密钥的归属保留。旧手机资料及草稿仍可访问，明确导入后才进入本机主日程；新配对不会把所有旧来源自动混合。v2 取消账号接口；旧 Supabase 数据不会被删除，但需要先在旧版导出，再另行迁移到本机，当前没有 Supabase 自动导入界面，不能直接把云端配置当成本机数据库。

## 功能边界

原生日程和有限规则解析在本机执行，离线可用；规则解析不是离线大模型。手机可直接选择“仅用离线规则”，无可用网络时也会使用规则；模型请求失败时保留原输入和草稿，用户可改用规则。

联网模型由发起整理的设备直接连接它自己的模型服务。手机只需能访问该服务，无需配对、无需电脑在线；电脑模型配置也不会成为手机的默认配置。配对网页只提供日程访问，隐藏智能整理和模型设置入口，相关接口拒绝配对凭据。具体配置和网络范围见[模型设置](model-settings.md)。

安卓后台同步、可靠后台/锁屏提醒、应用内离线大模型、自动网络发现和端到端加密同步尚未提供。
