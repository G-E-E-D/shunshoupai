# 顺手排 v1.4.0 · 保持登录与手机离线日程

Windows 安装 `shunshoupai-desktop-v1.4.0-setup.exe`；安卓使用正式签名 `shunshoupai-android-v1.4.0.apk` 覆盖升级。建议两端一起更新，保留既有账号和日程。

## 打开就能接着用

- Windows 加密保存登录凭据，重启自动恢复；默认本地会话 30 天有效，活跃使用自动续期，临时断网保留登录。
- 手机直接进入原生日程，无需电脑在线或先注册即可新增、修改、完成、删除和搜索。
- 初次关联电脑后自动合并两端日程；前台重连继续同步，重复请求不重复创建，删除记录也会同步。
- 不同日程时间重叠时保留双方并提示；同一日程同时修改时保留手机稿，由用户选择版本。

## 减少重复操作和丢稿

三端自动保留编辑草稿，安卓旋转屏幕后继续填写，桌面“暂不保存”也保留改过的表格。编辑期间另一端更新时展示冲突，明确确认后才采用新版本。桌面无变化刷新保持滚动和焦点，手机日程优先展示，常用按钮扩大触摸范围。

## 升级与边界

安卓 versionCode=5，沿用原正式签名；Windows 升级和卸载保留用户数据。SQLite 自动创建同步表，Supabase 部署须追加 `20261027030000_offline_sync.sql`。

手机离线功能用于原生日程；智能整理和模型设置仍需服务在线。同步在手机前台及回到应用时进行，后台/锁屏同步和可靠提醒尚未实现。数据按服务地址和账号隔离，电脑地址变化后的旧分区待同步数据需恢复原地址再同步；跨地址设备识别与迁移尚未实现。Supabase 临时扫码授权继续遵循 JWT 到期时间。

## 验证

本地已通过 103 项服务测试、Web/API 集成与冲突补测、Qt 原生编译及 CTest 4/4（含发布版本检查）、Android 35 模拟器 19/19。另验证手机先离线记日程，再扫码合并电脑重叠安排，两端均保留全部内容。发布附件取自本版本通过验收的 CI，附 SHA256SUMS.txt 和安卓签名证书摘要。
