# 顺手排 v2.1.0 · 独立手机体验与 Java 截图整理

本版在 `main` 实现。Windows 保留现有 Qt 桌面主体和 Node 本机服务，新增悬浮窗、全局快捷键、框选截图与 OCR 使用 Java；Android 新增功能同样使用 Java。

## 新增体验

- **电脑截图整理**：按 Ctrl+Alt+S 框选文字，或启用可拖动浮窗。中英文 OCR 在本机完成，运行时和模型随安装包提供。核对文字后进入原来的日程草稿表格，确认后才保存。
- **手机浮窗取字**：首页“取字”开启系统屏幕捕获，切换应用后点击浮窗框选。无需连接电脑，本机识别、文字校正、规则整理与保存均可独立完成。
- **手机完整本机工作台**：独立模型设置、中文规则整理、可编辑批量草稿、月历、全局搜索和前台提醒。断网仍可管理日程并使用有限规则整理。
- **配对只同步日程**：任意两台原生设备保留各自副本，日程合并方式不变；配对凭据不能调用对端模型、读取模型设置或获得电脑工具会话。
- **中断可恢复**：已有输入、草稿和待核对保存结果受到保护；识别文字可稍后继续，重复回传不会重复追加或自动保存。

## 使用与升级

Windows 打开应用后可按 Ctrl+Alt+S；浮窗默认关闭，在截图设置中开启。手机在“取字”中按系统要求授权悬浮显示、通知及屏幕捕获。新的捕获会话需要重新授权，同一会话内可多次框选。锁屏、停止或系统撤销后不继续截图。

Android versionName **2.1.0**、versionCode **9**，沿用正式签名。建议两端一起升级；本机日程、草稿和已有配对资料保留。手机模型需在手机自行设置，不从配对电脑复制密钥。

截图不发送到模型服务；点击整理后，确认的文字可能发送到该设备配置的模型服务。Android 使用随包 ML Kit 模型，其 SDK 可能发送性能与使用指标；详见[截图说明](https://github.com/G-E-E-D/shunshoupai/blob/main/docs/screenshot-ocr.md)。

安卓同步接收和日程提醒目前依赖应用前台运行，不保证后台或锁屏提醒；截图前台服务不能替代这项限制。没有离线大模型、iOS 客户端或端到端加密同步。请在可信局域网中配对。
