# 顺手排 v2.0.0 · 无账号日程与局域网设备配对

安装后直接打开使用，不再注册、登录或记密码。电脑和手机各自保存主日程；任意两台电脑或安卓手机可在可信局域网扫码、识别二维码图片或粘贴链接配对，包括手机↔手机，无需固定中心电脑。

## 日常流程

- 打开即用：Windows 自动建立本机身份；Android 未配对也能新增、编辑、完成、删除和搜索。
- 扫码配对：任一设备生成 90 秒有效的一次性码，另一端确认共享范围后合并日程，不必等待网页登录。
- 之后自动同步：连接可用时尝试合并，断线修改保留在本机；安卓应用需保持前台才能接收同步。
- 并发内容不覆盖：修订及祖先关系支持多设备环路合并，并发修改或删除保留全部不同版本，由用户明确选择。
- 设备可管理：查看已配对设备、解除授权；解除后已保存日程继续保留，未配对的局域网设备不能访问。
- 地址可变化：同一设备更换 IP 后重新扫码，核对稳定身份后继续同步，不向新地址发送旧凭据。

配对会共享本机全部日程及未来修改，内容可能经对方继续传播至其他已配设备。解除配对不能撤回已经传播的副本；模型配置和密钥不通过日程同步传播。

## 升级与数据保留

建议电脑和手机一起升级到 v2.0.0。Android versionCode=6，继续使用既有正式签名。Windows 升级和卸载保留本机数据。

旧版单份本机资料沿用，事件 ID、旧编辑与待确认操作所依据的版本、模型配置和草稿继续保留；多份旧资料仅在本机首次选择。历史资料明确导入后才进入主日程，不会因为新配对就把所有旧来源混合。旧 Supabase 数据保持原样，v2 不再将其作为运行后端，需要先在旧版导出后另行迁移，目前没有自动导入界面。

## 当前范围

支持电脑与安卓手机任意两两连接和多设备传播。安卓接收服务仅在前台运行；后台同步、可靠锁屏提醒与离线 AI 尚未实现。手机 Web 智能整理和模型设置仍需要配对电脑在线。

身份签名和设备凭据用于授权与数据隔离，局域网 HTTP 本身不提供端到端加密，请使用自己信任的局域网。模型请求仍发送到用户自行配置的模型服务。

本机已完成服务、Web/API、Qt 与 Android 多设备验证。正式安装包从同一源码提交通过的 CI 获取，发布页记录对应流水线，并附 SHA256SUMS.txt 和签名证书摘要。
