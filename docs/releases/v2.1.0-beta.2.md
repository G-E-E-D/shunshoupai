# 顺手排 v2.1.0-beta.2 · 手机独立完整体验

手机现在拥有与桌面对应的完整原生日程工作台，未连接电脑、甚至未配对任何设备也可以使用。两端配对只用于同步日程。

## 手机新增体验

- 一句话安排在手机整理成草稿，可修改标题、选择日期时间、删除或取消勾选，再批量确认。保存入口固定在底部，输入和未保存草稿退出后继续保留。
- 手机独立配置、测试和保存兼容 Chat Completions 的模型。请求由手机直接发往自己指定的服务；密钥用 Android Keystore 加密，仅留在手机。
- 无模型或完全断网时，本机有限规则仍能整理。模型故障时保留输入，可明确切换规则；不会把规则结果冒充模型响应。
- 新增月历与日程计数、七天视图、已完成与恢复、搜索、开始前五分钟的本机前台提醒。
- “明天”等日期表达以实际上海日期为参考，不因浏览未来日历而改变。
- 批量保存使用 SQLite 事务和稳定编号：一个坏条目整批回滚，重试不重复创建，也不复活已删除的日程。

## 配对仅同步日程

已移除手机的电脑工具和 WebView 工作台依赖。配对凭据不能调用另一端的 AI、模型设置或远端网页会话；本机模型设置、密钥、未确认草稿与提醒偏好不参与日程复制。已有的任意两设备配对、离线合并和显式冲突选择继续保留。

## 升级与边界

本版沿用独立 `beta` 分支的 Go 后端，属于预发布版本，不覆盖 `main` 稳定分支。Windows 安装目录仍与原版本相同；安装前关闭应用并备份完整本机数据目录。Android versionCode=8，沿用正式签名，直接覆盖升级，勿卸载来代替升级。

手机不需要电脑在线，但网络模型仍需要手机能连接其服务；没有内置离线大模型。同步接收和开始前提醒要求应用在前台，可靠后台/锁屏通知尚未提供。局域网配对继续要求可信网络，不代表 HTTP 已端到端加密。

正式 Windows 安装器与 Android APK 只从同一源码提交全部通过的 CI 获取，发布页附对应运行记录、SHA256SUMS.txt 和 Android 证书摘要。
