# 顺手排 v1.1.0 · Android 客户端

新增 Android 安装包，支持 Android 8.0 及以上版本。请下载本页的 **shunshoupai-android-v1.1.0.apk**，在 Android 上打开安装。

## 使用方式

1. 电脑先按 README 启动日程服务：`npm ci`、`npm run build`、`npm run start`。
2. 手机和电脑连接同一局域网。在安卓应用里填入电脑地址，例如 `http://192.168.1.20:3000`；已有公网部署时填写对应的 HTTPS 地址。
3. 登录与电脑相同的账号，即可整理、编辑、确认保存和同步日程。手机上的 `localhost` 代表手机自身，请使用电脑的局域网 IP。

## 本次新增

- 原生服务地址配置、记忆和切换入口。
- 应用内日程工作台，复用现有登录、草稿确认、日程管理和跨端同步。
- 原生返回、刷新、加载与网络错误重试。
- 正式发布签名；附 APK SHA-256 校验文件和签名验证信息。

这是连接现有服务的 Android 客户端，APK 不内置后端。电脑本地服务停止后，应用无法继续访问该服务；公网体验需要自行部署。模型密钥继续放在服务端，未配置时使用明确标记的规则解析。提醒仍仅在前台页面活跃时工作。

首次安装可能需要为当前下载来源开启“安装未知应用”权限。建议保持 Android System WebView 更新。公网服务使用 HTTPS，HTTP 仅用于可信局域网演示。

完整说明见 [Android 安装和构建文档](https://github.com/G-E-E-D/shunshoupai/blob/main/docs/android.md)。
