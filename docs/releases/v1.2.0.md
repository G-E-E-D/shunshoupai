# 顺手排 v1.2.0 · 原生桌面与扫码登录

本次同步更新 Windows 桌面与 Android 客户端。源码、构建脚本和文档保存在仓库，安装包只放在 Releases。

- **Windows：** 下载 `shunshoupai-desktop-v1.2.0-setup.exe`，运行安装后即可打开。C++ / Qt 原生界面，包含 Qt 与本地服务，不需要另装 Node 或打开网页。
- **Android：** 下载 `shunshoupai-android-v1.2.0.apk`，支持 Android 8.0+，沿用正式签名可覆盖 v1.1.0。

## 原生桌面与 Java / C++ 安卓

Qt Widgets 提供日程整理、草稿确认、日程管理、模型设置和扫码登录。安卓在原 Java 工程中加入 NDK / JNI，地址校验、同源判断和扫码协议由双方共享的 C++ 核心处理；Java 保留平台界面、相机和应用内 WebView。

## 用户接自己的模型

桌面“模型设置”或安卓“偏好与账号 → 模型设置”填写 Base URL、模型名称和 API Key，先测试连接，再保存。个人配置按账号隔离，跨端共用，Key 在服务端加密存储，仅读回掩码。

日程提示词固定在服务端，用户不需要填写。模型接口需兼容 Chat Completions 和 JSON 输出；测试会产生一次小型请求。

## 一次扫码，连接并登录

电脑登录后点击“手机扫码登录”，选择手机可访问的局域网地址，生成 90 秒有效、只能使用一次的登录码。安卓首页点击“扫码连接”，扫描后自动登录同一账号。

登录码是短时授权凭据，请勿截图转发。它不包含密码、长期会话或模型 Key。手机和电脑需能访问同一服务；本地模式保持同一 Wi-Fi、允许端口 43127，电脑应用保持打开。

本地兑换获得独立会话。可选 Supabase 模式只授权至源 access JWT / 会话上限到期，届时重新扫码或密码登录，不复制 refresh token。

## 升级与数据

Windows 重装和卸载保留 `%LOCALAPPDATA%/Shunshoupai/data/`。备份数据库时同时备份同目录加密主密钥。

已有源码/远程后端需更新代码、安装依赖并重新构建启动。Supabase 按顺序追加个人模型迁移和扫码配对迁移，设置稳定的 `MODEL_SETTINGS_ENCRYPTION_KEY`（32 字节随机值 Base64）；本地 SQLite 自动初始化。仅更新安卓 APK 不会替代已有远程后端升级。
