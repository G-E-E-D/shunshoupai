# 顺手排 v2.1.0-beta.1 · Go 后端试用版

本次版本在独立 `beta` 分支将后端迁移为 Go；原 `main` 分支保留稳定版代码。

- Windows 随包启动 Go 服务，使用静态手机工作台，运行时无需 Node.js。
- 保留无账号、本地优先、扫码授权、双向设备配对和多设备因果同步。
- 沿用 SQLite、设备身份、加密密钥、旧请求编号与日程版本，保留并发修改及删除标记。
- 模型配置、规则解析、兼容 Chat Completions 接口迁入 Go。
- Android 版本同步为 2.1.0-beta.1，versionCode=7，沿用正式签名。

这是预发布版本。安装前关闭程序并备份完整数据目录和原生客户端设置。Windows beta 使用原安装位置，会更新当前安装；卸载和升级仍保留本机数据。设备协议保持兼容，但建议参与测试的设备一起更新。

局域网 HTTP、安卓前台接收同步、手机智能整理依赖在线电脑等边界保持不变。详见 [Go 构建与迁移](https://github.com/G-E-E-D/shunshoupai/blob/beta/docs/go-backend.md)。

安装器与正式签名 APK 均须来自同一提交通过的服务、Windows 和 Android 流水线；发布附件提供 SHA-256 校验与 Android 证书摘要。
