# 顺手排 v2.2.0 · 手机后台提醒与自动同步

手机切到后台、返回桌面或锁屏后，日程提醒和设备同步可继续运行。本版在 main 使用 Java 实现，保留现有电脑主体和去中心化配对方式。

## 本次更新

- **系统闹钟提醒**：开始前五分钟发通知，进程被系统回收后仍可触发；点击通知打开对应日期。完成、删除、改期和同步冲突会重新核对，避免过时提醒和重复提醒。
- **后台自动同步**：已配对设备由独立后台连接服务保持可达，不必一直停留在日程页面。网络恢复自动尝试，断线逐步减少重试，系统任务提供补同步。
- **重启恢复**：手机重启首次解锁或覆盖升级后，自动恢复已启用的提醒和后台连接。
- **一次设置**：首页显示实际权限状态，集中设置通知、准时提醒与锁屏运行，普通启动不重复弹窗。可以从运行通知或“提醒与后台运行”中暂停后台同步，配对关系和本机数据保留。

## 使用与升级

打开手机应用后，按首页提示完成一次设置。新安装默认启用日程提醒和配对后的后台同步，旧版本明确关闭的提醒选择保留。允许通知后才能显示提醒；有已配对设备时建议允许不受电池优化限制，以免深度休眠阻断局域网连接。

Android versionName **2.2.0**、versionCode **10**，沿用原正式签名。请直接覆盖安装，不要先卸载。Windows 同步发布同版本安装包，保留 Java 截图与既有功能。

配对仍只交换日程，不传模型密钥、截图或未确认草稿。屏幕取字是独立会话，锁屏仍会停止；后台同步不会读取屏幕或调用模型。

系统强行停止后需重新打开一次。厂商自启动/省电限制、通知关闭及勿扰模式仍会影响运行；后台任务由系统调度，不保证每隔固定秒数执行。详见[后台使用说明](https://github.com/G-E-E-D/shunshoupai/blob/main/docs/background-operation.md)。

发布要求同一提交的服务、Windows 和 Android 流水线全部通过，并核对安装包版本、签名与 SHA-256。Android 增加真实后台及锁屏双向同步、系统任务、通知去重与取消、进程退出后的 Doze 闹钟，以及真实重启后的提醒和服务恢复验证。完整流水线链接与产物校验结果随 GitHub Release 提供。
