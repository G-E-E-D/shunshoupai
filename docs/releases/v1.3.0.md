# 顺手排 v1.3.0 · 现代界面与纯 Java 安卓修复

Windows 下载 `shunshoupai-desktop-v1.3.0-setup.exe` 一键安装；安卓下载 `shunshoupai-android-v1.3.0.apk` 覆盖升级，沿用原签名，保留数据。

## 更清爽的原生桌面

参考 Google 日历与 Material 的蓝白配色、留白和圆角分组，重做主工作台、登录/注册、草稿、日程编辑、模型和扫码设置。日期选择器改为原生圆形日期、今天/选中状态和清晰的月份导航，支持键盘操作；不再使用旧系统网格与橙色导航。

桌面仍为 C++ / Qt Widgets 原生界面。新版有真实对话框交互测试，覆盖注册、手工编辑、草稿确认保存和日期选择，不只生成效果图。

## 安卓恢复纯 Java，保留扫码登录和模型设置

按用户反馈撤销安卓 NDK / JNI / C++ 依赖，回到 Java 工程，同时保留一次性扫码自动登录、个人模型、固定提示词和同步。原生连接页与日程界面也改为统一蓝白样式。

旧版会将加载 100% / onPageFinished 当作显示成功；空文档可被误判并一直白页。本版复用原 WebView，显示原生加载状态，等待可交互内容和可绘制帧，保留超时、原生重试及软件兼容渲染。增加同来源重新扫码、返回前台、刷新及旧服务 404 回退回归。

用户报告来自红米 K80 / Android 16；当前尚未在该实体手机上复现或验证具体 GPU 根因，安装后仍需实机复验。不是将问题简单归因于 C++。

## 升级

建议电脑和手机一起更新。桌面升级/卸载保留用户数据目录，安卓 versionCode=4，支持覆盖旧正式版本。旧服务无 `/mobile` 时，新安卓可同来源回退根入口，但新功能仍需要对应服务端接口。

扫码码有效 90 秒且仅用一次，请勿转发。API Key 按账号加密保存，系统提示词固定在服务端。数据库与模型密钥备份规则不变。

验收结果和 SHA-256 将在整包验证通过后补入。[桌面说明](https://github.com/G-E-E-D/shunshoupai/blob/main/docs/desktop.md) · [安卓说明](https://github.com/G-E-E-D/shunshoupai/blob/main/docs/android.md)
