## 可复现的人工流程

1. 新建自己的本地账号，输入 README 主演示句，检查三条草稿。取消后刷新应没有新增记录。
2. 重新整理并保存；重启服务，登录后仍能查询。
3. 在另一浏览器登录同账号，修改、完成或删除；第一浏览器回到前台后应同步。
4. 两端基于相同版本发出不同编辑，旧版本应被拒绝，刷新后重新确认。
5. 断网后保存不能显示已同步；对响应丢失请求沿用原编号确认，不能重复新建。
6. 注册第二账号，列表不应显示第一账号的记录，接口也不能修改其 ID。
7. 按 [云端配置](cloud-setup.md)填入真实账号后，重复上述流程并补录实际环境和耗时。
