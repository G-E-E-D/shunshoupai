正式安装包仅从同一源码提交通过的服务、Windows、Android CI 提取，版本、签名与文件哈希另行核对；执行记录及附件见 [v2.0.0 发布页](https://github.com/G-E-E-D/shunshoupai/releases/tag/v2.0.0)。

## 人工复现

1. 安装并打开 Qt 桌面，注册自己的虚构账号，输入 README 示例句；取消草稿不应产生正式日程。
2. 再次整理并确认，重启应用、重新登录后应仍能查询；修改、完成/恢复、删除行为正常。
3. 保存个人模型配置，在安卓同服务同账号查看；Key 只显示掩码。
4. 电脑生成登录码，安卓扫码后应自动登录同账号；已用或过期码应要求重新生成。
5. 两端同时编辑同一版本，旧版本应被拒绝。断网或丢响应时使用原保存编号核实，不重复创建。
6. 注册第二账号，不应查看或修改第一账号的事件与模型配置。
7. 重装、卸载后确认用户数据目录保留；按需要备份数据库与同目录加密主密钥。
