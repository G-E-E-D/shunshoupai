# 手机独立体验验收矩阵（v2.1.0-beta.2）

本轮以原生 Windows 桌面的日常功能作为基准，手机的安排、整理和模型设置应直接在手机完成。配对仅用于日程交换，不开放对端 AI、模型设置或管理权限，也不是开启基本功能的条件。

以下要求已纳入本轮自动化；真实执行范围见文末，不把模拟器或受控模型结果扩展为所有真机和模型服务均可用。

| 使用流程 | 桌面现有行为 | 手机验收要求 | 验证方式 |
| --- | --- | --- | --- |
| 第一次打开 | 自动建立本机身份，不需账号 | 未配对也能进入本机日程，创建、整理、查看和设置模型 | 全新应用数据启动，不设置电脑地址 |
| 手动安排 | 新建、编辑、删除、完成、恢复 | 操作立即保存在手机，电脑关闭不阻塞 | 设置一个不可达的已配设备，执行操作并重建 Activity |
| 一句话整理 | 有限规则或自配模型生成草稿 | 无模型时本机规则可用；模型由手机直接请求 | 本机规则测试及受控 HTTP 模型服务器 |
| 含糊输入 | 显示追问，不猜时间 | 如“周五三点”先追问，不写正式日程 | 检查提示与数据库无新增 |
| 批量确认 | 修改标题和时间、移除行后显式保存 | 整批写入原子且可重试；一个坏条目不能部分落库 | 无效批次回滚、同请求重复保存、不同内容误用同编号 |
| 草稿恢复 | 原文、解析表格和手动编辑分别持久化 | 退出 review、旋转或重开仍保留修改和删除的行；恢复不自动提交 | 实际界面编辑、Activity 重建、检查正式日程数 |
| 模型设置 | 测试、保存、掩码、留空保留 Key、移除 | 手机独立设置；测试不自动保存，换来源不能带旧 Key | 实际 HTTP 请求、独立加密存储、重建后读取 |
| 模型失败 | 显示错误并保留输入 | 断网、无效响应或权限错误时不清输入、不写日程，可明确改用规则 | 受控错误响应及关闭模型服务器 |
| 日程视图 | 当天、所选日期起七天、已完成 | 同等入口与状态持久化；搜索和完成恢复可用 | 含当天、第六天、第七天及已完成项目的真实界面 |
| 前台提醒 | 开始前五分钟，应用保持打开时生效 | 本机提醒不依赖配对；完成、删除、冲突不误提醒，重复轮询不重复提示 | 可控参考时间与前后台生命周期 |
| 多设备 | 各端独立副本，重连后合并，冲突显式选择 | 新手机功能写入同一本机主日程，保留原复制协议 | 已有双手机、双电脑及手机电脑同步回归 |
| 数据边界 | 设备模型 Key 不通过日程同步传播 | 手机 Key 留在手机；解除配对不影响本机模型和日程 | 检查同步负载及解除后继续本机使用 |

## 断网与电脑关闭分别验收

- **电脑关闭、手机能上网**：手机手动安排、本机规则、草稿、视图和提醒可用；手机自配模型仍能直连其服务。
- **手机完全断网**：手动安排、本机规则、草稿、视图和前台提醒可用；互联网模型请求不可用，输入和未提交草稿必须保留。
- **两台设备重新互通**：只交换已确认的日程及其修改；未提交草稿和模型密钥不随日程交换。

前台提醒不是系统闹钟承诺。应用被关闭或系统停止运行时不承诺提示；界面和说明须明确这一点。

## 测试隔离

独立 instrumentation 使用虚构日程和临时模型 Key，不调用付费模型。测试模型服务与配对服务使用不同端口；即使存在不可达的电脑 peer，本机模型请求仍须只到达用户配置的模型端点。截图不得包含真实 API Key、个人安排或仍可使用的配对凭据。
