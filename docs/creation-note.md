# 创作说明

顺手排来自一个小烦恼：安排说起来一句话，填进日历却要点很多次。我用 Codex 辅助实现 C++ / Qt 原生桌面端和 Java 安卓客户端。v2.0.0 取消日程账号流程，电脑和手机打开即可记录；需要同步时，在可信局域网扫描一次性二维码配对。

文本先整理成可修改草稿，确认后才保存。每台设备离线继续记日程，连接后合并；不可变修订及完整祖先关系保留并发修改和删除，由用户明确选择。重点处理跨午夜、重复请求、编辑冲突和旧资料升级，保留事件版本与未完成草稿。模型配置由用户自行提供，没有模型时明确使用规则解析。

电脑和安卓手机可任意两两配对，包括手机↔手机，无需固定中心电脑。共享日程可能经对方继续传播到其他已配设备，解除配对无法撤回已有副本；模型密钥不传播。手机与桌面都提供独立的整理、模型设置、批量草稿、日历视图和前台提醒；配对只同步日程。安卓接收同步需保持前台，互联网模型需要当前设备到其服务的网络。身份签名用于识别设备，不等于 TLS 或端到端加密；地址变化需要新二维码重新授权。

交付包括源码、Windows 安装器、Android APK 和教程，演示视频尚未发布。当前功能见[设备配对说明](device-sync.md)，实际验证范围见[验收记录](acceptance.md)。
