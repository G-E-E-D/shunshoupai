# Android 客户端（v2.1.0-beta.1）

手机打开即进入原生日程，无需账号或电脑连接。新增、编辑、完成、删除和搜索都先在本机保存；需要与另一台手机或电脑合并时再扫码配对。智能整理和模型设置使用配对电脑提供的 Web 工作台，需要电脑在线。

[下载 APK](https://github.com/G-E-E-D/shunshoupai/releases/download/v2.1.0-beta.1/shunshoupai-android-v2.1.0-beta.1.apk) · [发布页](https://github.com/G-E-E-D/shunshoupai/releases/tag/v2.1.0-beta.1)

应用 ID 为 `com.shunshoupai.app`，`versionName=2.1.0-beta.1`、`versionCode=7`，最低 Android 8.0 / API 26。客户端使用 Java，无需 NDK、JNI 或 CMake。正式覆盖升级必须使用同一正式签名；不要卸载来代替升级，否则会删除手机本机数据。

## 日常使用与配对

1. 安装后直接记录日程，未配对时也能使用。
2. 需要同步时，任一手机或电脑打开 v2.1.0-beta.1，在设备连接入口展示一次性二维码。
3. 两端连接同一可信局域网，另一端扫码或粘贴配对链接，确认共享范围。
4. 回到日程即可继续使用。手机前台及回到应用时自动尝试同步；断线期间继续本机保存。手机只有在前台才开放接收服务，退到后台或关闭应用后不能被另一端同步。

支持安卓↔安卓、安卓↔电脑和多设备连接，无需固定中心电脑。Windows 安装版监听 **43127**，手机接收地址和端口以配对页面为准；同步时接收端需运行并允许可信局域网访问。手机的 `localhost` 指手机自己。普通地址不是授权凭据，未配对设备不能借此读取日程。

二维码 90 秒有效且只能兑换一次，重新生成会作废该入口的旧码。配对通过原生请求完成；长期凭据使用 Android Keystore 加密保存，网页只获得 HttpOnly Cookie，不通过 JS 桥获得原生凭据。

任一设备地址变化后，必须在原设备生成新二维码并重新扫描。手机验证稳定设备身份和已记录公钥后继续同步；新地址不会收到旧的长期凭据。身份签名仅用于识别设备，不提供 HTTP 加密，不能替代 TLS；请只在可信局域网使用。

## 本机数据与解除配对

每台手机有一份本机主日程，配对会合并双方全部日程及未来修改，内容也可能经对方流转至其其他已配设备。模型密钥不随日程传播。取消配对停止后续授权，已经保存的副本仍留在各设备上；不能撤回已传播的数据。离线解除时，也应在另一端设备列表中撤销授权。

不同日程重叠时保留双方并提示；同一日程并发修改或删除冲突时保留全部不同版本，展示标题、时间、状态和来源，由用户明确选择，不默认选最新时间。同步使用不可变修订和完整祖先关系，重试及环路传播不会重复创建或复活旧删除；编辑仍以打开时读到的版本为基线。

编辑草稿自动保留，旋转后可恢复。升级会保留旧日程、版本、待确认操作编号和仅有表单草稿的旧空间。历史资料仍可访问，明确导入后才合入主日程，其他来源不会因空间 ID 相同或一次新配对就自动合并。

## Web 工作台与历史兼容处理

原生日程不依赖 WebView 加载。打开“电脑工具”时，原生端先建立已配对的网页连接，再加载所选电脑的 `/mobile`。这里的智能整理和网页日程操作在该电脑上进行，手机原生日程仍独立保存；未配对网页只显示连接说明，不提供注册或密码入口。

历史 v1.2.0 曾出现扫码后的空白网页问题，v1.3.0 起加入原生加载状态、界面可交互与可绘制帧检查、超时重试和兼容渲染。v2 保留相关恢复机制，但旧版账号接口已取消，设备配对和同步应将两端一起升级。历史模拟器结果不代表所有厂商真机均已验证。

## 从源码构建

需要 JDK 17、Android SDK Platform 36、Build Tools 35.0.0，以及仓库内 Gradle Wrapper。

```sh
cd android
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
```

Windows 使用 `gradlew.bat`。正式签名由以下环境变量提供：

```text
ANDROID_KEYSTORE_PATH
ANDROID_KEYSTORE_PASSWORD
ANDROID_KEY_ALIAS
ANDROID_KEY_PASSWORD
```

设置后运行 `./gradlew :app:assembleRelease :app:lintRelease`。调试签名不能覆盖正式包；证书、口令、APK 和数据库不应提交到仓库。

当前不提供可靠的锁屏/后台提醒、后台同步或离线 AI。具体构建、模拟器、相机及真机验证范围见[验收记录](acceptance.md)，完整协议见[设备配对](device-sync.md)。
