# v2.1.0-beta.2 约两分钟演示脚本（待录制）

使用当前 Windows 与 Android 构建以及虚构日程。不注册演示账号。尚未录制或发布视频；没有真实模型配置时保留“规则解析”标记，不能用模拟器画面冒充实体相机拍摄。

| 时间 | 画面 | 旁白 |
| --- | --- | --- |
| 0–15 秒 | 打开电脑原生窗口和未配对手机 | 不用账号，打开就能安排。 |
| 15–35 秒 | 手机未配对，输入一句话、编辑批量草稿后保存 | 整理、修改与保存都在手机完成，不需要电脑。 |
| 35–60 秒 | 电脑输入示例句、检查并修改草稿后保存 | 一句话整理，确认后才写入正式日程。 |
| 60–85 秒 | 手机 A 展示配对码，手机 B 扫码并确认共享范围 | 两台手机也能直接配对，无需中心电脑；全部日程可经对方继续传播。 |
| 85–105 秒 | 电脑识别手机二维码图片或粘贴链接，三端合并 | 连接时自动合并，断线时各自保存；并发版本由你明确选择。 |
| 105–115 秒 | 设备列表、模型设置，隐藏敏感字段 | 配对可取消，已传播副本无法撤回；模型密钥不传播。 |
| 115–120 秒 | v2.1.0-beta.2 Releases 与源码页面 | 安装包和源码都在发布页。 |

发布画面中遮挡仍有效的二维码和 API Key。地址变化需重新生成二维码，不能通过填写新地址复用旧凭据。身份签名不是 TLS，演示范围是可信局域网；手机接收同步需保持应用前台，模型由各端直接访问自己配置的服务，配对只同步日程，后台同步及锁屏提醒不作承诺。
