# 约两分钟展示脚本（待录制）

使用 Qt 桌面客户端和安卓应用，注册虚构账号。当前只交付源码、安装包和教程，尚未录制或发布视频。无真实模型配置时保留“规则解析”标记；相机识别与真机操作需要实际拍摄，不能用模拟器结果冒充。

| 时间 | 画面 | 旁白 |
| --- | --- | --- |
| 0–15 秒 | 双击安装 EXE，打开原生 Qt 窗口 | 一段话能说完的安排，不必反复填表。 |
| 15–40 秒 | 输入主演示句，整理三项草稿，修改一项时间 | 确认前只是草稿，标题和时间都能改。 |
| 40–60 秒 | 保存，右侧出现日程；修改、完成或恢复 | 数据真实保存，重复请求有防重，冲突会提示。 |
| 60–85 秒 | 电脑生成一次性码，安卓扫码自动登录 | 手机不用再输入密码；码只有 90 秒、只能使用一次，请勿转发。 |
| 85–100 秒 | 手机修改，电脑刷新看到结果 | 同一服务同一账号接着用，前台约八秒补拉。 |
| 100–115 秒 | 桌面/安卓模型设置，隐藏 Key | 用户接自己的兼容模型，提示词由软件固定。 |
| 115–120 秒 | Releases 与源码地址 | 安装包在 Releases，仓库保留源码和构建步骤。 |

不要在录制中显示真实 Key、密码或仍有效的登录二维码。真实模型、Supabase、公网和真机测试的实际范围以验收记录为准。
