# 约两分钟展示脚本（待录制）

本次交付选择图文教程。以下是后续录制可直接使用的脚本，不代表视频已经制作或发布。

准备两个浏览器会话，或真实手机与电脑，登录同一账号。使用虚构日程。未配模型时，画面保留“规则体验”标识，旁白如实说明；有可用密钥后再录真实 AI 等待过程。手机视口模拟应标为模拟，不能称为真实手机实测。

| 时间 | 画面 | 旁白/字幕 |
| --- | --- | --- |
| 0–10 秒 | 一段杂乱安排与空日程并排 | “一句话能说完的安排，填进日历却要点很多次。” |
| 10–35 秒 | 输入主演示句，点击整理，展示三张草稿 | “顺手排先把它变成草稿。这里的日期和时间可以直接改，确认前不会保存。” |
| 35–60 秒 | 修改一项标题或时间，确认；另一会话刷新出现记录 | “两端登录同一账号，读取同一份数据库。前台每八秒、切回页面或手动刷新都会查询。” |
| 60–80 秒 | 输入“周五三点面试”，展示补充问题 | “时间不明确就补充信息，不把猜测直接写进日历。” |
| 80–95 秒 | 另一会话编辑；第一会话刷新显示变化 | “保存有防重和版本检查，避免连点重复、旧内容覆盖新安排。” |
| 95–110 秒 | 展示账号设置中的解析方式和提醒说明 | “当前是上海时区单次日程。提醒只在页面前台工作，后台和锁屏还不支持。” |
| 110–120 秒 | 仓库与 README 启动命令 | “源码和图文教程都在仓库，Node.js 24 即可先运行本地版本。” |

若录制时未配置模型，补一句：“本次演示使用有限规则解析；填写自己的服务端密钥后可切换真实模型。”不要用预先录好的卡片冒充实时响应。
